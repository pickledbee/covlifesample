# Covenant Life Presbyterian Church website (sample)

Redesign of covenantlifeopc.com.

- index.html: the website (GitHub Pages serves this file)
- apps-script/: copy of the Google Apps Script project (sheet builder, admin page, data feed). This copy is for safekeeping; the live script runs in Google Apps Script.

The website reads events, announcements, groups and "This Sunday" from the Google Sheet through the Apps Script web app URL set in SHEET_FEED_URL inside index.html.
